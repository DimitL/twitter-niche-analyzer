# AGENTS.md

## Repository expectations
- Работай пошагово: один законченный шаг за раз.
- Не переходи к следующему крупному этапу, пока не завершён текущий.
- Не ограничивайся теорией: по возможности создавай реальные файлы и код.
- Если архитектурное решение неоднозначно, сначала предложи лучший вариант и кратко обоснуй.
- Все пользовательские тексты интерфейса и отчётов — на русском языке.
- Код, имена переменных, комментарии в коде и технические названия файлов — на английском.
- Проект: веб-приложение для анализа Twitter/X без официального API.
- Основной способ сбора данных: Playwright + Chromium.
- Цель продукта: находить перспективные ниши для ведения Twitter/X-блога.
- Итоговый результат должен включать топ-10 ниш с объяснениями.
- Для каждой ниши нужно 10 релевантных influencer accounts.
- Ключевой приоритет анализа: engagement relative to follower count.
- Учитывай баланс: growth potential + monetization potential + ease of content production.
- Делай архитектуру модульной: frontend, backend, shared logic.
- Предпочтение: сначала создать хороший каркас проекта, потом постепенно наращивать функциональность.
- Не добавляй лишнюю сложность без необходимости.
- Если селекторы X окажутся хрупкими, выноси их в отдельный централизованный файл.
- После важных изменений предлагай git checkpoint.
